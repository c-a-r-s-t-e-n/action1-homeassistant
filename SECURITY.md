# Security policy

This is an experimental, read-only community integration. Do not rely on it as your sole source of patch, CVE or endpoint status information.

**Never report secrets or private infrastructure data in a public GitHub issue.** Do not include API Client IDs/Secrets, OAuth bearer tokens, endpoint/organization identifiers, user names, serial numbers, IP addresses, raw audit events, original API responses or logs containing these values.

If you suspect a vulnerability that could expose credentials, please use GitHub's private vulnerability reporting mechanism if enabled, rather than opening a public issue. Rotate any exposed credentials in Action1 immediately.

Credentials are held in Home Assistant config-entry storage. Restrict dashboard and backup access accordingly. All Action1 cloud data is supplied by Action1 and may be delayed or inaccurate.
